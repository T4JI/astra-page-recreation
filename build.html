04 / What needed fixing

The original build’s gaps.

The failures below became concrete changes before the version 3 handoff. The later scattered startup and its fix are recorded above.

01

Stars moved as a shape, but did not respond locally.

Miss: a cursor could rotate the field, but could not properly brush individual stars aside.

Change: per-particle displacement and velocity, recovery toward the moving path, pointer capture, cancellation, and replay cleanup.

02

The spiral settled into a mostly static picture.

Miss: idle motion did not reproduce continuous inward flow or replenishment at the outer ends.

Change: five reference paths, continuous travel, endpoint fades, recycled particles, and a rotating core. The scene keeps its particle count constant.

03

The visual proportions were close, but off.

Miss: oversized labels, a low spiral center, crowded stars, and an overly compact bright core.

Change: reference-based placement and label sizing, smaller star details, revised highlights, and a softer central glow. Bloom remains a canvas approximation.

04

Not every inspection or hosting route worked.

Issue: direct requests to the reference could return HTTP 403; the first hosting route could not meet the public-access requirement.

Change: used browser-accessible page evidence and published the static site through GitHub Pages.

05

Configuration defaults were not the rendered truth.

Issue: the first source configuration suggested two generic paths, 12,000 particles, and a perspective camera.

Change: traced the active runtime to five authored paths and orthographic projection before rebuilding the hero. The active page, rather than a generic configuration, became the reference.

06

Source chart data needed a working adapter.

Issue: escaped currency formats, an unmapped color token, and inconsistent legend identities affected rendering and highlighting.

Change: normalized formatting, theme colors, and model identities, then executed the real chart specifications. All 155 rendering cases passed before the first handoff.

07

Replacing tab panels broke some return links.

Issue: citation targets could disappear with inactive panels, and repeated return links did not consistently scroll.

Change: restored the correct tab before scrolling and normalized return anchors. The later harness completed 34 citation return actions and reopened 32 copied chart links.

What this demonstrates, and what it doesn’t

The original build used a live reference and existing assets and required two user corrections. A third website correction later removed the scattered startup. The current star rendering approximates the original effects; it is not a claim of pixel-perfect equivalence. Some media and interactive demonstrations are embedded from their original hosts. Original assets, article content, and benchmark results were reused; the build did not create those demonstrations or independently validate the model claims.

The original 12 checks validate animation behavior. The later completed verification covered 14 animation checks and 7 archive/navigation checks in two runs. Neither is an exhaustive test of every link, media host, device, or accessibility requirement. No independent visual similarity score was recorded. Cost estimates are separate from verification counts and actual billing.
